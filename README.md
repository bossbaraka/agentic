# 🟢 بوت واتساب الذكي — WhatsApp AI Agent

بوت واتساب تفاعلي يردّ على العملاء بالعربية عبر **WhatsApp Cloud API الرسمي**،
بدماغ **Google Gemini**، مع **لوحة تحكم حية** تتيح لك مراقبة كل محادثة والتدخل يدويًا في أي لحظة.

```
┌──────────┐   webhook    ┌──────────────────────────────┐    API     ┌─────────┐
│ واتساب   │ ───────────▶ │  خادم Fastify (هذا المشروع)  │ ────────▶ │ Gemini  │
│ العميل   │              │  ─ تحليل وتوحيد الرسائل      │           └─────────┘
└──────────┘              │  ─ جلسات وسياق وملخصات       │
     ▲                    │  ─ فهم صور/صوت/PDF           │    live    ┌─────────┐
     │   رد مقسّم         │  ─ أدوات (حجز/طلب/تذكرة)     │ ◀────────▶ │ لوحة    │
     └─────────────────── │  ─ تحويل لموظف بشري          │   WebSocket│ التحكم  │
                          └──────────────────────────────┘            └─────────┘
```

---

## ✨ المزايا

| الميزة | التفصيل |
|---|---|
| 🧠 **سياق حقيقي** | يحفظ المحادثة، ويلخّصها تلقائيًا عندما تطول، ويستأنف بعد فترة الخمول |
| ⏳ **تجميع الرسائل** | العميل يرسل ٣ رسائل متتابعة؟ البوت ينتظر ويردّ **مرة واحدة** بشكل متماسك |
| 🖼️ **فهم الوسائط** | صور، رسائل صوتية، فيديو، وملفات PDF — تُمرَّر لـ Gemini مباشرة |
| 🔧 **أدوات (Function Calling)** | حجز موعد، الاستعلام عن طلب، فتح تذكرة، إرسال كتيّب |
| 🙋 **تحويل لبشري** | تلقائي عند الغضب/الشكوى/نقص المعلومة، أو يدوي بأمر `/بشري` |
| 🖥️ **لوحة تحكم حية** | كل رسالة تظهر فوريًا، تردّ يدويًا، تغيّر حالة أي محادثة |
| 📚 **قاعدة معرفة** | علّم البوت عن نشاطك بملفات Markdown — بدون لمس أي كود |
| ⌨️ **مؤشر "يكتب…"** | يعلّم الرسالة مقروءة ويظهر مؤشر الكتابة قبل الرد |
| 🔒 **أمان** | تحقق HMAC من توقيع Meta، كبح معدل، حماية من حقن التعليمات |
| 🧪 **وضع تجربة كامل** | جرّب كل شيء بدون رقم واتساب وبدون مفاتيح |

## 🚀 البدء في ٣ دقائق (وضع التجربة)

```bash
npm install
cp .env.example .env
npm run start
```

في طرفية **ثانية**:

```bash
npm run demo          # سيناريو محادثات جاهز
npm run demo -- chat  # أو: حوار تفاعلي تكتبه بنفسك
npm test              # ١٤ اختبارًا على السلوكيات الحرجة
```

ولوحة التحكم على: **http://localhost:3000/admin**

> في وضع التجربة الردود تأتي من **محرك قواعد بسيط** وليس Gemini — الهدف تجربة المسار كاملًا.
> أضف `GEMINI_API_KEY` في `.env` لتفعيل الذكاء الحقيقي فورًا.

## 🔑 تفعيل الذكاء الحقيقي (Gemini)

1. افتح **https://aistudio.google.com/apikey** وأنشئ مفتاحًا (مجاني).
2. في `.env`:
   ```env
   DEMO_MODE=false
   GEMINI_API_KEY=ضع_المفتاح_هنا
   GEMINI_MODEL=gemini-2.5-flash
   ```
3. أعد التشغيل: `npm run start`

| الموديل | متى تستخدمه |
|---|---|
| `gemini-2.5-flash-lite` | أرخص خيار، كافٍ للأسئلة المباشرة |
| `gemini-2.5-flash` | **الموصى به** — توازن سعر/جودة/سرعة |
| `gemini-3.5-flash` | أذكى، للحالات المعقّدة (أغلى) |

## 📱 ربط رقم واتساب حقيقي

الدليل المفصّل خطوة بخطوة مع لقطات الشاشات: **[SETUP.md](./SETUP.md)**

### المختصر

```bash
# 1) أنشئ تطبيقًا في developers.facebook.com وفعّل WhatsApp
# 2) انسخ من صفحة API Setup:
WHATSAPP_ACCESS_TOKEN=EAA...
WHATSAPP_PHONE_NUMBER_ID=106540352242922
# 3) من App settings → Basic:
WHATSAPP_APP_SECRET=...
# 4) اختر كلمة سر بنفسك وضعها هنا وفي Meta:
WHATSAPP_VERIFY_TOKEN=كلمة-سرية-تختارها
DEMO_MODE=false

# 5) افتح نفقًا عامًا للخادم المحلي:
npm run tunnel
```

ثم في **Meta for Developers → WhatsApp → Configuration**:

| الحقل | القيمة |
|---|---|
| Callback URL | `https://الرابط-من-النفق/webhook` |
| Verify Token | نفس `WHATSAPP_VERIFY_TOKEN` |
| Webhook fields | اشترك في **messages** |

أرسل رسالة لرقم الاختبار — وسيردّ البوت 🎉

## 🧭 لوحة التحكم

`http://localhost:3000/admin`

- **📚 إعادة تحميل** قاعدة المعرفة بدون إعادة تشغيل الخادم

> 🔒 قبل النشر: اضبط `DASHBOARD_PASSWORD` في `.env`.

## 📚 تعليم البوت عن نشاطك

كل ملفات `.md` داخل مجلد `knowledge/` تُحقن تلقائيًا في تعليمات النموذج،
ويعتبرها **المصدر الوحيد الموثوق** — إن لم تكن المعلومة هناك، يحوّل لبشري بدل التخمين.

```
knowledge/
├── business-info.md      ← الأسعار، الدوام، التوصيل، سياسة الإرجاع
└── tone-and-replies.md   ← النبرة وأمثلة على ردود جيدة وسيئة
```

أضف ملفات بحرية: `products.md`، `faq.md`، `policies.md`…
وللتحديث دون إعادة تشغيل: زر 📚 في اللوحة، أو:

```bash
curl -X POST http://localhost:3000/api/knowledge/reload
```

## 🔧 إضافة أداة جديدة (Function Calling)

الأدوات الحالية في `src/agent/tools.ts` ترجع **بيانات تجريبية**.
لربطها بأنظمتك الحقيقية، عدّل جسم الدالة فقط:

```ts
async check_order_status(args, ctx) {
  const row = await db.query('SELECT * FROM orders WHERE id = ?', [args.order_id]);
  if (!row) return { ok: false, data: { found: false } };
  return {
    ok: true,
    data: row,                                    // ما يراه النموذج
    userMessage: `طلبك ${row.id} حالته: ${row.status_ar}`,  // يُرسل للعميل مباشرة
  };
}
```

**لإضافة أداة جديدة** (٣ خطوات):
1. تعريفها في `TOOL_DECLARATIONS`
2. تنفيذها في `TOOL_HANDLERS`
3. ذكرها في كتلة الأدوات داخل `src/agent/systemPrompt.ts`

## ⚙️ أهم الإعدادات

| المتغير | الافتراضي | الشرح |
|---|---|---|
| `BOT_MODE` | `hybrid` | `business` خدمة عملاء / `assistant` مساعد شخصي / `hybrid` الاثنين |
| `BOT_NAME` | `مساعد` | اسم البوت كما يقدّم نفسه |
| `BUSINESS_NAME` | `الشركة` | اسم النشاط |
| `MAX_REPLY_PARTS` | `3` | أقصى عدد رسائل في الرد الواحد |
| `HISTORY_TURNS` | `24` | كم رسالة سابقة تُرسل للنموذج |
| `SESSION_TTL_MINUTES` | `45` | خمول بعدها تُعتبر المحادثة جديدة |
| `RATE_LIMIT_PER_MIN` | `15` | حد رسائل العميل في الدقيقة |
| `GEMINI_THINKING_BUDGET` | `0` | `0` = أسرع وأرخص، `-1` = النموذج يقرر |
| `TYPING_INDICATOR` | `true` | مؤشر "يكتب الآن…" |
| `HUMAN_AGENT_ID` | *(فارغ)* | رقم الموظف الذي يستقبل تنبيهات التحويل |

القائمة الكاملة مع الشرح في `.env.example`.

## 🌐 نقاط الـ API

| الطريقة | المسار | الوظيفة |
|---|---|---|
| GET | `/webhook` | تحقّق Meta (`hub.challenge`) |
| POST | `/webhook` | استقبال الأحداث (يتطلب توقيعًا صالحًا) |
| GET | `/health` | حالة الخادم والإحصائيات |
| GET | `/admin` | لوحة التحكم |
| GET | `/ws` | WebSocket للأحداث الحية |
| GET | `/api/sessions` | قائمة المحادثات + الإحصائيات |
| GET | `/api/sessions/:key` | محادثة واحدة بسجلّها الكامل |
| POST | `/api/sessions/action` | رد يدوي / تغيير حالة |
| POST | `/api/sessions/delete` | تصفير محادثة |
| POST | `/api/knowledge/reload` | إعادة تحميل قاعدة المعرفة |
| POST | `/internal/simulate` | محاكاة webhook (وضع التجربة فقط) |

## ⚠️ قيود يجب أن تعرفها من WhatsApp

| القيد | التفصيل |
|---|---|
| **نافذة ٢٤ ساعة** | بعد آخر رسالة من العميل لديك ٢٤ ساعة للرد بحرية. بعدها **يجب** استخدام قالب معتمد (Template) |
| **حد الرسالة** | ٤٠٩٦ حرفًا — المشروع يقسّم تلقائيًا عند `MAX_SEGMENT_CHARS` |
| **التسعير** | المحادثات تُحتسب حسب الفئة (marketing / utility / authentication / service). ردود الخدمة داخل نافذة ٢٤ ساعة غالبًا مجانية أو الأرخص |
| **الحظر** | لو أبلغ المستخدمون عن رسائلك كإزعاج، قد يُقيَّد رقمك |
| **الرقم** | الرقم المسجّل في Cloud API لا يمكن استخدامه في تطبيق واتساب العادي في نفس الوقت |

## 🩺 استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| Meta ترفض الـ Callback URL | تأكد أن الرابط **HTTPS**، وأن `WHATSAPP_VERIFY_TOKEN` مطابق تمامًا، وأن الخادم يعمل والنفق مفتوح |
| `401 invalid signature` في السجلات | `WHATSAPP_APP_SECRET` خاطئ — انسخه من App settings → Basic |
| البوت لا يرد | تحقق: `DEMO_MODE`؟ هل المحادثة في حالة `human`؟ هل تجاوز العميل `RATE_LIMIT_PER_MIN`؟ |
| `API key not valid` | مفتاح Gemini خاطئ أو غير مفعّل — أعد إنشاءه من AI Studio |
| الردود بطيئة | اضبط `GEMINI_THINKING_BUDGET=0` واستخدم موديل `flash` |
| الردود طويلة جدًا | قلّل `MAX_SEGMENT_CHARS` وشدد على الاختصار في `knowledge/tone-and-replies.md` |
| الوسائط لا تُفهم | تأكد من `MAX_MEDIA_BYTES` وأن التوكن يملك صلاحية الوسائط |
